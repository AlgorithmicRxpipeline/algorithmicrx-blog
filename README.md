# AlgorithmicRx Blog

Technical writing from AlgorithmicRx — an AI-driven drug discovery company focused on rare diseases, currently building **DAPC**, an in silico target-discovery pipeline for Duchenne Muscular Dystrophy.

## What's here

This repo holds posts covering:

- **Tool and method evaluations** — walkthroughs of computational biology and AI tooling we test as part of our own workflow (protein structure prediction, cloud compute for structural biology, etc.), written as honest assessments rather than endorsements.
- **DAPC progress notes** — technical updates on our own pipeline, clearly scoped as MVP-stage, in silico work without experimental validation unless stated otherwise.
- **Field notes** — shorter pieces on the broader landscape of AI-for-rare-disease drug discovery.

## Ground rules for content in this repo

- Say what stage something is at. MVP is MVP; no wet-lab validation isn't glossed over.
- If we didn't build it, we say so explicitly.
- No marketing overclaiming — this is written for a technically literate audience.
- Core pipeline IP (scoring, ranking logic) stays out of this repo and out of [`AlgorithmicRx_DAPC`](https://github.com/AlgorithmicRxpipeline/AlgorithmicRx_DAPC); that repo documents the pipeline's approach, not its internals.
